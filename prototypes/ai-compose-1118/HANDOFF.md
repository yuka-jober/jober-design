## 3. 현재 화면 구조 (11/19 실서비스처럼 왼쪽 대화 + 오른쪽 탭으로 합침. 직전 탭 구조는 `index-v3.html`)
- **맨 왼쪽 회색 사이드바 (232px, 실서비스처럼 상단 바 없음)**: 로고·AI 알림톡·접기 버튼 / 새 메시지 / 오늘(지금 대화, 제목은 안내 종류)·어제·지난 30일. 지난 대화는 시안용 예시라 누르면 "열 수 없어요" 알림. **접으면(64px)** 자버 심볼 + 새 메시지·대화 아이콘만, 대화 아이콘에 마우스를 올리면 목록 팝오버, 심볼을 누르면 펼침. 1240px 이하는 접힌 채 시작, 접기 상태는 브라우저에 기억. **모바일**은 위쪽 회색 띠(로고 + 새 메시지 + 대화 아이콘 → 아래로 팝오버). **왼쪽 아래 스페이스 바꾸기**(실서비스처럼): 스페이스 이름 + 워크스페이스 + ⌃ → 위로 스페이스 목록(`.menu`). 시안용 예시 4개(카페모먼트·헬스라이프 강남점·해법수학학원·바른치과), 다른 곳을 고르면 "시안에서는 바꿀 수 없어요". 접으면 머리글자 타일만, 목록은 오른쪽으로. 모바일 위쪽 띠에는 없다.
- **왼쪽 대화 열 (400px)**: **방금 주고받은 것만** 보인다 — 새로 말하면 내 말이 대화 열 맨 위로 올라가고 그 아래 방금 받은 답 + 지금 질문 하나(구분선 + 답 버튼/확인 박스, 준비되면 보내기 버튼과 광고 동의 체크). 지난 대화는 위로 스크롤해야 보인다 (`#log` 지난 대화 / `#turnNow` 방금 것, 화면 한 장 높이). 지금 질문 아래에 추천 말 **세로 목록 최대 3개**(앞에 ↵ 아이콘, 되돌리기는 되돌리기 아이콘)(되돌리기·나에게 먼저 보내보기·요금 문의·번호 넣는 법만 — 바꾸기를 권하는 말은 넣지 않는다). 맨 아래 입력창(기본 두 줄). 보내면 내 말풍선이 올라오고, 0.8초 '입력 중' 점 → AI 답과 지금 질문이 차례로 나타난다(`THINK_MS`). 일반 문의(요금 등)도 여기서 답하고 오른쪽 화면은 그대로.
- **오른쪽 폴더 탭 — 보고 다듬는 곳 (11/19: 할 일은 모두 왼쪽 대화로)**: `알림톡 / 받는 사람` 2개. 다 된 탭은 원형 체크.
  - 알림톡: 알림톡 폰(노란 칸 직접 고치기) + (버튼이 있으면) 상세 문서 폰. 말투 고르는 동안은 완성본 3개 비교.
  - **상세 문서 글자도 폰에서 바로 고친다**(11/19): 제목·인사말·섹션 이름·각 줄·질문·선택지(`data-edit`). 평소엔 받는 그대로, 올리면 노란 칸, 누르면 고치기 상태. 처음 고칠 때 지금 문서를 `state.doc`에 옮겨 저장(이후 알림톡 칸을 바꿔도 페이지는 따라오지 않음). `(광고)` 표시는 고칠 수 없다. '문서 수정'·'문서 고치기'(자버 서식 편집 자리)는 뺐다. 섹션 추가·삭제·레이아웃 변경은 나중에 실서비스처럼 '섹션 선택 + 말로 고치기'로.
  - 받는 사람: **보기만**. 보낼 사람 N명 + 명단별 인원 + 중복 번호(누구와 같은지) + 번호 오류 목록. 비어 있으면 "아직 받는 사람이 없어요".
  - 보내기 설정 탭은 없앴다 — 예약은 대화의 보내기 단계, 요약은 최종 확인 창.
- **대화에서 하는 일**: 받는 사람 단계에 [엑셀 파일 올리기] [번호 붙여넣기(입력창에 바로)] → AI가 "보낼 사람 N명, 같은 번호 N명은 한 번만, 번호가 틀린 N줄은 뺐어요" 요약 + 받는 사람 탭이 열림. 명단 빼기는 말로("명단 빼줘", 20명 이상이면 확인 창). 보내기 단계에 큰 [N명에게 지금 보내기] + [예약하기]. 예약하기(또는 "예약할래요")를 하면 AI가 **"언제 보낼까요?"** 묻고 [오늘 오후 6시][내일 오전 10시][직접 고르기](+예약 중이면 [지금 보내기]) 세로 목록, 또는 말로 답한다(`parseWhen()`: 내일 3시 / 금요일 오후 2시 / 다음 주 화요일 / 25일 3시 반 / 11월 28일 14:30 / 내일 아침…, 지난 날·못 알아들으면 다시 묻는다). "내일 3시에 예약해줘"처럼 한 번에 말하면 바로 예약. 예약 후엔 [예약 시각 바꾸기].
- **좁은 화면(≤860px, 11/19)**: 한 화면 구조. **위에 작은 미리보기(높이 44vh)가 늘 보이고 아래가 대화.** 작은 미리보기는 스크롤 없음: 알림톡 | 상세 페이지 폰을 0.48배로 나란히(넘치면 아래 흐림), 말투·템플릿 비교는 0.6배, 받는 사람 탭은 글씨가 14px 아래로 내려가지 않게 줄이지 않는다. 오른쪽 아래 **[크게 보기]**(`#sheetBig`)로 화면 전체 미리보기(`sheet(true)`, X로 닫음, 닫으면 폰 위치를 처음으로). 크게 볼 땐 대화를 가린다(답하려면 X로 닫는다). 말투·템플릿 비교 땐 크게 보기를 저절로 열고 고르면 닫는다(`autoSheet`). 크게 볼 때 알림톡 | 상세 페이지는 한 장씩, 둥근 화살표(`phGo()`), 상세 페이지를 만들 땐 상세 페이지 쪽부터(`showPage()`). **대화는 방금 말과 지금 질문만** 보이고, 그 전 대화는 맨 위 **[이전 대화 보기]**(`#logToggle`, `.show-log`)로 펼친다. 새 답이 오면 방금 말부터 보이게 맨 위로. AI 말의 '오른쪽에서'는 좁은 화면에선 '미리보기에서'(`where()`). 최종 확인 창은 화면 전체: 미리보기만 스크롤, 요약·동의·버튼은 아래 고정, 상세 페이지·링크가 있으면 둥근 화살표로 넘긴다(`.sc-wrap`, `.sc-nav`). ≤560px 첫 화면은 예시 그림을 빼고 입력창을 바로 보인다.
- **탭 자동 전환**: 단계가 바뀌면(예: 버튼 고르기 → 받는 사람) 그 탭으로, AI에게 말하면 내용을 보고 관련 탭으로 넘어간다 (`talkTab()`: 번호·엑셀·명단 → 받는 사람, 말투·이모지·문서 → 알림톡, 예약·요금 문의 등은 탭 그대로). 넘어간 탭은 두 번 반짝인다. 탭을 직접 눌러 보는 건 언제든 된다.
- **맨 아래**: 다음 행동 칩 + 입력창.
- **상세 페이지 만들기**: 누르면 상세 페이지 폰에 글자가 앞에서부터 채워지는 애니메이션(시안 15초, 실제 약 30초 → `GEN_MS`). 위 AI 말은 단계 문구가 바뀐다. 다 만들면 바로 넘어가지 않고 "이대로 쓸까요?" + `이대로 쓸게요 / 문서 고치기` 로 확인받는다.

### 진행 순서 (한 번에 하나만 묻는다 · 11/19 정리)
1. **확인할 것** — 빠진 칸, 요일 오류, 나중에 넣은 광고 문장. 여러 개면 하나씩, 하늘색 박스.
   - **다른 템플릿 추천**(11/19): 처음 만든 직후(확인·말투 단계, 버튼 고르기 전) 추천 말에 [다른 템플릿 추천해줘]. 누르거나 "다른 템플릿", "템플릿 바꿔/추천"이라고 하면 오른쪽에 지금 템플릿('지금' 표시) + 같은 원문으로 만든 다른 템플릿 2개, 모두 3개를 나란히 보여준다(`tplPicks()`, `tplBubble()` — 지금 상태는 건드리지 않고 미리 만들어 본다). 각 아래 [이걸로 할게요], 대화엔 같은 순서의 이름 목록. 지금 템플릿을 고르면 그대로 쓴다. 바꾼 뒤 되돌리기 가능. 실서비스는 만든 뒤 템플릿을 채팅으로 바꿀 수 없고 다시 붙여넣으라고 안내한다.
2. **말투는 단계로 묻지 않는다**(11/19): 추천 말투로 먼저 넣어 두고, 추천 말 [다른 말투로 보여줘](확인·버튼 단계, 상세 페이지 확인 단계)나 "말투 바꿔줘"로 언제든 오른쪽에서 비교해 고른다. 지금 말투에 '지금' 표시. 상세 페이지로 문장을 옮긴 뒤엔 그 페이지 문장에 말투를 입히고(알림톡 안내 한 줄은 그대로), 내용이 빠지지 않게 '짧게'는 뺀 두 가지만 보여준다. 페이지 확인 중에 바꿨으면 다시 "이대로 쓸까요?"로 돌아온다. 되돌리기 가능. 버튼을 먼저 정해야 알림톡에 남는 문구가 확정되므로 말투를 앞에 고정하지 않았다.
3. **자세히 보기 버튼** — AI 추천을 맨 앞에, 그다음 '내 링크 연결하기'(실제로 가장 많이 쓴다) → '상세 페이지 만들기' → '버튼 없이'.
   - **고르기 전엔 아무것도 붙이지 않는다**: 미리보기에 페이지·자세히 보기 버튼·수신거부 없음. AI 판단은 추천과 이유로만 보여준다.
   - 보내던 문자에 링크가 있으면 링크를 추천하고 주소를 입력칸에 미리 채운다.
   - **원문이 1,000자를 넘으면**(`ALIMTALK_MAX`): 만들 때부터 들어가는 앞부분까지만 알림톡에 넣고, 남은 문장은 `state.overflow`에 보관한 뒤 "남은 N문장"을 바로 알려준다(보낼 수 없는 알림톡은 만들지 않는다). 버튼 단계에선 상세 페이지를 추천하고, 페이지를 만들면 알림톡 문장 + 남은 문장을 모두 페이지에 담는다. 링크·버튼 없이를 고르면 "남은 N문장은 빼고 보낼게요"라고 알린다. (말투 등으로 1,000자를 다시 넘으면 `tooLong()`이 페이지 없이는 다음으로 못 넘어가게 막는다.)
4. (상세 페이지를 고르면) 만드는 과정(시안 15초) → "이대로 쓸까요? 글자는 눌러서 바로 고칠 수 있어요" (이대로 쓸게요)
   - **처음엔 원문을 모두 알림톡(추가메시지 칸)에 넣고, 페이지가 다 만들어지면 겹치는 문장을 알림톡에서 뺀다**(11/19, `moveToDoc()`): 페이지 내용을 굳혀 두고 추가메시지를 `MOVED_LINE`("자세한 내용은 아래 [자세히 보기]에서 확인해 주세요.") 한 줄로 바꾼 뒤 "안내 N문장은 페이지에 담고…"라고 알려 준다. 되돌리기 가능. 링크·버튼 없이로 바꾸거나 "상세 페이지 빼줘"면 `restoreMoved()`로 문장을 알림톡에 돌려놓는다.
   - 이때 추천 말 [설문 문항을 추가해줘] [인사말을 짧게 해줘] — 말로도 고칠 수 있다는 걸 보여준다. 문항 추가는 AI가 "어떤 문항을 추가할까요?" 묻고 추천 문항(연락 방법 / 참석 인원 / 남기실 말씀, 이미 있는 건 빼고) 목록을 주거나, 넣고 싶은 문항을 말로 답한다(`addQuestion()`). 넣은 문항은 폰에서 잠깐 표시되고, 되돌리기 가능, 끝나면 다시 "이대로 쓸까요?". "설문 문항 빼줘"도 된다.
5. **받는 사람**: 엑셀 파일 올리기 / 번호 붙여넣기 두 가지만.
6. **보내기**: 대화의 큰 버튼 → **최종 확인 창** "이대로 보낼까요?" (왼쪽: 알림톡 미리보기(말풍선 300px, 스크롤 없이 다 보임) + 상세 문서가 있으면 나란히(알림톡과 같은 높이에서 스크롤), 링크면 '자세히 보기 링크' 칸(주소 전체 + [새 창에서 열어 보기]) / 오른쪽 열: 받는 사람·보내는 시각·예상 비용 세로 요약, 광고성이면 보내기 버튼 바로 위에 동의 체크, 보내기·취소. 창 높이가 미리보기만큼이라 1440×800에도 스크롤 없이 들어간다. 모바일은 세로로 쌓고 창 전체 스크롤) → 5초 취소 알림. 중간에 바뀐 게 있을 수 있어 반드시 한 번 더 보게 한다. 예약은 보내기 버튼 아래 [예약하기] → 대화로 시각을 정한다.
7. **보낸 뒤 + 발송 내역 (11/19)**: 대화 하나가 발송 하나. 지금 보내면 결과 숫자(받음 | 못 받음, 10명 이상이면 시안용으로 2명 못 받음: 카카오톡 미사용 1, 일시적 오류 1)와 [N명에게 다시 보내기](일시적 오류만, 확인 창 거쳐서), 못 받은 사람과 이유는 받는 사람 탭 '보낸 결과'. 예약이면 [보내는 시각 바꾸기](다시 예약하기 전까지 원래 예약 유지) | [예약 취소](확인 창, 취소하면 보내기 전 단계로). 왼쪽 대화 목록엔 보낸 대화에 '발송완료', 예약한 대화에 '예약' 알약만. 사이드바 [발송 내역](`#hist`, `openSends()`): 자버 사이트 모양(회색 바닥 + 흰 카드 32) 표 하나 — 일시(대화한 일시) | 내용 | 받는 사람 | 결과(예약이면 예약 일시) | 비용. 비용은 포인트(10원 = 1P, 1건 5P, `pt()`). 이 탭에서 보낸 건 `sessionStorage`(`ai-compose-1118-sent`)에 남고, 지난 대화는 시안용 예시라 열리지 않는다. 기존 자버 폴더 발송 목록과의 연결은 논의 중.

- **광고(11/19 실서비스에 맞춤)**: 광고 문장은 알림톡 본문에서 따로 빼 두고(`state.pageAds`), 상세 페이지를 만들면 그 페이지에 넣어 `(광고)` 표시. 링크·버튼 없이로 가면 "광고 문장은 넣을 곳이 없어서 빼고 보낼게요". 광고가 페이지에 들어갔거나 쿠폰이면 수신거부 자동 포함 + 보낼 때 "받는 사람 N명 모두 광고 수신에 동의했어요" 체크.
- 용어는 **상세 페이지**로 통일 (예전 '상세 문서' 표현을 바꿈).

## 4. 사용자가 정한 규칙 (꼭 지킬 것)
- **설명·보고는 항상 한국어.**
- 승인된 템플릿만 사용. 템플릿 고정 문구는 못 바꾸고 변수·추가메시지 칸만 바뀐다. 승인 신청 흐름 넣지 않기.
- 자버는 **문자·브랜드메시지·친구톡을 못 보낸다** → 그런 기능 넣지 않기.
- 알림톡 변수·추가메시지 칸에 **이모지 넣어도 됨** (실무에서 많이 보냄).
- `#{수신자명}` 같은 사람마다 바뀌는 칸은 **값만**(이름만, 호칭 X). 모두에게 같은 칸은 "11월 30일까지"처럼 도움말 붙여도 됨.
- 한 번에 여러 선택을 내밀지 않기. **작은 버튼(바꾸기·토글 등)은 최대한 없애기.**
- **채팅에서 설정 바꾸기를 권하지 않는다.** "더 짧게·이모지·말투·예약" 같은 제안 대신 "바꾸고 싶은 게 있으면 알려 주세요".
- **작은 안내·설명 문구는 기본으로 넣지 않는다.** 꼭 필요하면 사용자 허가 먼저. "~해요"체 설명조·당연한 말 금지 (11/19 미리보기 위 안내 줄·질문 아래 회색 줄·카드 설명·첫 화면 캡션 모두 삭제). 꼭 알아야 할 내용은 질문 위 AI 말(`#qSay`)로 합친다.
- 화면 문구 구분자는 가운데점(·) 대신 `|`.
- 최소 글자 크기 14px. 화면 문구에 긴 대시(—) 쓰지 않기. 카드 안에 카드 넣지 않기(연한 구분선).
- 사용자가 조작할 수 있는 건 되돌릴 수 있게.
- 디자인 토큰 규칙은 `/Users/yuka/jober-design/CLAUDE.md` 참고 (raw hex 금지, 토큰 사용 등).
- 실제 발송 금지. 자버 실서비스 확인은 **커넥티아 스페이스에서 읽기만**. 실제 연락처를 프로토타입에 넣지 않기. 깃 푸시·배포는 요청 있을 때만.
