# 알림톡 AI 상세 페이지 템플릿 (ai-page-kit)

AI가 상세 페이지를 매번 새로 디자인하는 대신, **정해진 템플릿·블록·색 프리셋 중에서 골라 내용만 채우도록** 하기 위한 디자인 규칙과 CSS 세트입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `kit.css` | 템플릿·블록·색 프리셋이 모두 들어 있는 CSS 한 장 (규칙은 파일 안 주석에도 있음) |
| `notice/*.html` | 공지형 예시 |
| `promo/*.html` | 프로모션형 예시 |
| `examples.html` | 예시 모음 |
| `palette.html` | 색 프리셋 미리보기 |

## 적용 방법

1. `kit.css`를 상세 페이지에 함께 넣는다
2. AI는 템플릿·블록 클래스를 골라 **마크업만** 쓴다. 새 색·폰트·장식을 만들지 않는다
3. 폼·버튼 색 등 페이지 바깥 요소도 고른 프리셋 색에 맞춘다

## 템플릿 고르기

| 메시지 구분 | 템플릿 | body / main |
|---|---|---|
| 안내 — 휴무, 휴강, 변경, 일정, 모임 | 공지형 | `<main class="page">` |
| 광고 — 할인, 이벤트, 가격표, 신상 | 프로모션형 | `<main class="page promo">` |
| 쿠폰 발급 페이지로 가는 경우 | 지금 쿠폰 페이지 유지 | — |

## 블록

| 블록 | 클래스 | 쓰는 곳 |
|---|---|---|
| 로고 | `.top > img.logo` / `.logo-text` | 맨 위 (이미지 없으면 상호 글자) |
| 히어로 | `.hero` / `.hero.is-dark` | 공지형에서 날짜 하나가 핵심일 때, 프로모션형에서 사진이 없을 때 |
| 제목 | `.title` (`.eyebrow` + `h1` + `.lead`) | 공지형 기본 |
| 프로모션 제목 | `.promo-head` (`.is-left` 왼쪽 정렬, `.hl` 형광펜 강조) | 프로모션형 |
| 대표 사진 | `.figure` (공지형) / `.arch` (프로모션형, `.is-wide`, `.is-empty`) | |
| 달력 | `.cal > .cal-row` (`.is-off` 휴무·마감) | 날짜 |
| 항목·값 | `dl.info` | 운영시간, 일시·장소 |
| 점 목록 | `ul.bullets` | 안내 사항 |
| 안내 판 | `.note` | 따로 알아 둘 것 |
| 혜택 판 | `.offer` | 큰 숫자 하나 (10%, 무료) |
| 혜택 목록 | `.offers` | 이벤트 여러 개 |
| 가격표 | `.menu > .menu-group > .menu-row` | 정가(취소선)·할인가 |
| 상품 카드 | `.items > .item` / `.items.is-media` (이미지 카드, 지그재그) | 신상·메뉴 |
| 아이콘 3개 | `.perks > .perk` | 특징 |
| 버튼 | `.pills > .pill` (`.is-line`, `.is-sm`) | |
| 연락처 | `.contact` | 맨 아래 |
| 조건 문구 | `.terms` | 광고 유의사항 |

## 색 프리셋 (`body.tone-*`)

버튼·아이콘 원·달력 윗줄에만 프리셋 색을 쓰고, 판·카드는 무채색, 글자는 `#111`.

| 클래스 | 버튼 색 | 버튼 글자 | 프로모션 배경 | 업종 |
|---|---|---|---|---|
| `tone-sky` | #1890FF (자버 파랑) | 흰색 | #EAF4FF | 학원·교육·공공·IT·통신·휴대폰·병원·의원·치과·피트니스 |
| `tone-mint` | #63B8B3 | 흰색 | #E6F5F3 | 약국·호텔·스파 |
| `tone-green` | #71B578 | 흰색 | #EBF5EC | 요가·건강·농산물 |
| `tone-lilac` | #AC90BB | 흰색 | #F3EDF7 | 뷰티·에스테틱·네일 |
| `tone-pink` | #F19195 | #111 | #FDECED | 꽃·선물·키즈·웨딩 |
| `tone-coral` | #F1815C | 흰색 | #FDECE5 | 음식점·세일·이벤트 |
| `tone-butter` | #EEC151 | #111 | #FFF4C4 | 카페·베이커리 |
| `tone-gray` | #111111 | 흰색 | #F4F4F6 | 헤어·패션·인테리어·기본값 |

고르는 순서: 로고에 색이 있으면 가장 가까운 프리셋 → 없거나 검정·회색이면 업종 → 모르면 `tone-gray`.
크림·베이지 계열은 쓰지 않습니다.

## 배경

| 경우 | 배경 |
|---|---|
| 공지형 | 흰 배경 + 회색 판 |
| 프로모션형 + 대표 사진 | `.promo-top`으로 로고·제목·사진을 감쌈 → 위는 흰색, 아래로 갈수록 색 배경 + 흰 카드 |
| 프로모션형 + 사진 없음 | 전체 색 배경 + 흰 카드 |
| 채팅 "배경 빼 줘" / "넣어 줘" | `body.bg-plain` / `body.bg-wash` |

## 참고

- 로고·사진(`.logo`, `.figure`, `.arch`, `.item-media`)과 버튼 링크는 이미지 첨부·링크 사용이 가능하다는 전제로 만든 예시입니다.
- 예시의 아이콘은 문서 안 `<symbol>`을 `<use>`로 불러옵니다. 적용 환경에 따라 `<path>`를 직접 넣어야 할 수 있습니다.
- 예시 HTML의 Pretendard jsDelivr 링크는 로컬 미리보기 전용입니다.
