## 바뀐 것

**인사관리 > 근태 관리 카드**
- 설명 3줄: 직원은 현재 위치와 함께 출퇴근을 기록하고 / 관리자는 제출된 기록을 확인해요 / 필요한 데이터는 엑셀로 내려받을 수 있어요
- 태그: GPS 위치 확인 | 기록 관리 | 엑셀 다운로드
- 자세히 보기 → 근태 관리 상세(`services/attendance/`)

**근태 관리 상세**
- 히어로: 출근하기 문서 이미지 확대, 내 위치에 조회 애니메이션(스피너 1초 → 좌표 → 주소 → 유지, 6초 반복, 동작 줄이기 설정 시 완료 상태만 표시). 실제 위치 조회는 하지 않는 시각 효과
- 기능 소개 3묶음(기록하기·실제 사용 예시 / 모아보기·직원별 확인 / 내려받기·기록 활용), 묶음마다 제목 2줄 + 설명 1줄 + 화면 예시 2개. 좌우 예시는 같은 폭·높이
- 이용 전 확인해 주세요: 인건비 관리 페이지와 같은 디자인(번호 01~03 + 항목 사이 구분선, 연한 회색 면)
- 섹션 세로 간격은 카카오 알림톡 상세와 같은 112px
