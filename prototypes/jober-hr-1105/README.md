# 자버 인사관리 — 메인 + 기능 상세 (개발 전달용, 통합 폴더)

인사관리 메인과 기능 상세 페이지를 **한 폴더, 한 주소**에서 관리한다. 기능 상세를 새로 만들거나 고칠 때마다 인사관리 메인의 카드 문구도 같이 바뀌므로, 메인은 여기 한 벌만 둔다.

- 배포: https://jober-hr.vercel.app (`/`는 인사관리 메인으로 이동)
- 이 폴더만 있으면 그대로 열린다. 메뉴의 다른 서비스(알림톡, 전자계약 등)는 전체 시안 사이트 https://jober-site.vercel.app 로 연결된다.
- 예전에 따로 만든 `jober-attendance-1102`, `jober-payroll-1103`은 이 폴더로 합쳐졌다. 앞으로는 이 폴더만 고친다.

## 인사관리 메인 (services/hr/)

- **히어로**: "입사부터 매일의 인사 업무까지 자버 하나로" / "계약서 따로, 연차 따로, 직원 정보 따로? 직원이 입력한 정보를 연락처에 저장하고, 계약서와 증명서에도 활용하세요." 버튼은 7가지 HR 서비스 살펴보기, 도입 문의
- **히어로 오른쪽 애니메이션** (`hr-hero.css` + 페이지 하단 스크립트): 서비스 패널처럼 생긴 카드 3장이 한 장면씩 나타남, 약 15초 주기 반복
  1. "김자버님이 직접 입력" 카드가 가운데 크게 → 항목 칩에 차례로 체크 → 제목 끝에 "완료" → 왼쪽 위 제자리로 이동
  2. 점선이 그려지며 "연락처 자동 저장" 카드가 나타남 → 생년월일, 휴대전화, 주소 값이 채워짐
  3. 점선이 그려지며 "근로계약서 자동 입력" 카드가 나타남 → 계약서 문장 속 빈칸(근로자, 생년월일, 주소)이 채워짐. 계약서는 아래로 이어지고 판 끝에서 잘림
  4. 계약서 오른쪽에 겹쳐 알림 2개("급여대장 업로드 완료", "연차 승인 완료")가 차례로 뜸 (모바일에서는 숨김)
  5. 잠시 멈춘 뒤 사라지고 처음부터
  - 카드 위치는 카드 높이를 재서 스크립트가 자동 계산(문구를 바꿔도 겹치지 않음). 1240px 이하에서는 글과 애니메이션을 위아래로 쌓음
  - 모바일과 동작 줄이기 설정에서는 움직임 없이 마지막 상태로 세로로 쌓임. 탭이 안 보이면 멈춤
  - 색: 흰·회색 면 + 자버 서비스 파랑 `#1890FF`만 (연한 연두·보라 면 쓰지 않음), 카드 모서리 8px
- **필요한 업무 바로 찾기**: 7개 서비스 바로가기
- **근태 관리 카드**: "직원은 현재 위치와 함께 출퇴근을 기록하고 / 관리자는 제출된 기록을 확인해요 / 필요한 데이터는 엑셀로 내려받을 수 있어요", 태그 GPS 위치 확인 | 기록 관리 | 엑셀 다운로드 → 근태 관리 상세
- **인건비 관리 카드**: 돈주머니 아이콘 옆에 제목, 한 카드를 둘로 나눔(모든 고객 / 급여 관리, 하나은행 고객 / 간편급여이체), 각 칸 설명은 한 줄, 자세히 보기는 다른 카드처럼 아래 오른쪽 → 인건비 관리 상세

## 근태 관리 (services/attendance/)

- 히어로: "출퇴근을 문서로 남기는 가장 간단한 방법" / "GPS 위치 기능이 있는 출퇴근 문서를 이용해보세요. 직원이 문서를 열면 현재 위치와 주소가 자동으로 표시돼요." 버튼 도입 문의, 출퇴근 기록 체험하기
- 히어로 출근하기 문서의 내 위치 칸: 조회 애니메이션(스피너 1초 → 좌표 → 주소 → 유지, 6초 반복). 실제 위치 조회는 하지 않는 시각 효과. 동작 줄이기 설정 시 완료 상태만
- 기능 소개 3묶음(기록하기·실제 사용 예시 / 모아보기·직원별 확인 / 내려받기·기록 활용), 묶음마다 제목 2줄 + 설명 1줄 + 화면 예시 2개(같은 폭·높이)
- 이용 전 확인해 주세요: 01 출퇴근 기록 작성 및 관리 / 02 전문 근태관리 기능 미지원 / 03 전문 근태관리 서비스 이용 권장
- 하단 CTA: 도입 상담하기, 전체 서비스 보기

## 인건비 관리 (services/payroll/)

- 히어로: "급여대장은 직접 업로드하고, 급여명세서는 일괄 발송하세요" / "업로드한 급여대장을 월별로 관리하고, 직원별 급여 내역을 간편하게 확인할 수 있어요." 버튼 도입 문의, 인건비 관리 체험하기(회원가입 모달)
- 주요 기능 카드 2장(머리줄 `아이콘 | 고객 | 기능명` 한 줄: 모든 고객 | 급여 관리, 하나은행 고객 | 간편급여이체), 급여대장 업로드 5단계(왼쪽 단계를 누르면 화면이 바뀜, 4단계 이름은 "항목 매핑", 업로드 창은 실제 크기 640px로 남은 칸 가운데), 급여명세서 발송·사업소득 관리, 하나은행 간편급여이체 STEP 1~3
- 이용 전 확인해 주세요: 01 급여 자동계산 및 임금대장 작성 미지원 / 02 급여대장 업로드 양식 제한 / 03 하나은행 간편급여이체
- 자주 묻는 질문 3개
- 사업소득 표는 옆 목업과 높이를 맞추려고 예시 직원 3명을 추가해 사업(5)로 표시

### 회원가입 모달 (개선안 10번 — 기존 '간편급여이체 진행하기' 모달 리디자인)

- "인건비 관리 체험하기"로 열림. 시안이라 **실제 가입은 되지 않음**
- 사이트 기존 전화 문의 모달과 같은 결. 색은 자버 디자인 시스템 파랑 `#1890FF`(필수 표시, 체크박스, 가입 버튼, 문의 링크), 필수 별표 `#F5222D`. 체크박스는 자버 디자인 시스템 `.checkbox` 규격
- 입력: 회사명·담당자 성함·이메일(필수), 어떻게 알고 오셨나요(선택). 약관: 모두 동의 + 필수 2개
- 필수 입력·동의 전에는 가입 버튼 비활성. 이메일 형식이 틀리면 칸을 벗어날 때 안내, 고치면 바로 사라짐
- 가입 버튼 → "가입이 완료됐어요"(시안). **실제 구현 시 현재 회원가입 완료 후 이동(급여대장 업로드 화면, 11번)과 연결**
- 간편 가입: 카카오(인라인 SVG)·구글·네이버 실제 로고. 기존 회원은 "급여 관리 이용 문의하기"(채널톡 `joberio.channel.io/home`)
- 확인 필요: '어떻게 알고 오셨나요?'가 현재 가입 필수값인지, 선택지 목록(지금은 예시)

## 공통 메모

- 섹션 세로 간격은 카카오 알림톡 상세와 같은 112px, 설명글과 목업 사이는 32px
- 목업 버튼·칩은 글자가 위아래 가운데 오도록 여백을 미세 조정함 (`payroll.css`, `attendance.css` 하단)
- 사이트 공통 검정 버튼(`.btn`)의 글자 높이는 건드리지 않음
