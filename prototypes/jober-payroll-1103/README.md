# 인건비 관리 상세 + 인사관리 카드 — 개발 전달용

이 폴더만 있으면 그대로 열린다. 인건비 관리 개편분만 따로 뺀 폴더이고, 메뉴의 다른 페이지 링크는 전체 시안 사이트(https://jober-site.vercel.app)로, 근태 관리 카드는 근태 관리 2차본(https://jober-attendance.vercel.app)으로 연결된다.

기준 개선안: 인건비 관리 클로드 작업 링크(1~11번 반영, 12번 이후는 이번 범위 아님).

## 파일

## 페이지 구성 (services/payroll/)

1. **히어로** "급여대장은 직접 업로드하고, / 급여명세서는 일괄 발송하세요" + 급여대장 화면 예시(크게). 버튼 "인건비 관리 체험하기" → 회원가입 모달
2. **주요 기능** 카드 2장: 급여 관리(모든 고객) / 간편급여이체(하나은행 고객, 태그는 하나은행 초록)
3. **급여대장 업로드** 5단계. 왼쪽 단계를 누르면 오른쪽 화면이 바뀜(키보드 화살표도 됨). 단계를 바꿔도 회색 판 크기 고정. 판 아래 "예시 화면 · 실제 데이터가 아닙니다"
4. **급여명세서 발송 / 사업소득 관리** 설명 2개 + 목업 2개, 두 목업 같은 높이
5. **하나은행 간편급여이체** STEP 1~3 카드(설명 + 미니 화면, 미니 화면 높이 통일) + i 아이콘 안내 "자버에서는 실제 급여이체가 진행되지 않아요."
6. **이용 전 확인해 주세요** 항목 4개, 번호 01~04 + 항목 사이 구분선
7. **자주 묻는 질문** 6개 (알림톡 상세와 같은 마크업)
8. **하단 CTA** "반복되는 업무는 줄이고, 사람에게 더 집중하세요" / 인건비 관리 체험하기 → 회원가입 모달, 전체 서비스 보기 → 인사관리
- 섹션 세로 간격은 카카오 알림톡 상세와 같은 112px

## 인사관리 > 인건비 관리 카드 (services/hr/)

- 한 카드를 둘로 나눔: 왼쪽 "모든 고객 / 급여 관리", 오른쪽 "하나은행 고객 / 간편급여이체"(초록)
- 자세히 보기 → 인건비 관리 상세
- 모바일에서는 위아래로 나뉨

## 회원가입 모달 (개선안 10번 — 기존 '간편급여이체 진행하기' 모달 리디자인)

- 히어로와 하단 CTA의 "인건비 관리 체험하기"로 열림. 시안이라 **실제 가입은 되지 않음**
- 사이트 기존 전화 문의 모달과 같은 결(둥근 28px 판, × 닫기, 알약 버튼). 색은 자버 디자인 시스템 파랑 `#1890FF`(필수 표시, 체크박스, 가입 버튼, 문의 링크), 필수 별표 `#F5222D`
- 체크박스는 자버 디자인 시스템 `.checkbox` 규격(16px, 모서리 2px)
- 입력: 회사명·담당자 성함·이메일(필수), 어떻게 알고 오셨나요(선택). 약관: 모두 동의 + 필수 2개
- 필수 입력·필수 동의를 마치기 전에는 가입 버튼 비활성. 이메일 형식이 틀리면 칸을 벗어날 때 안내, 고치면 바로 사라짐
- 가입 버튼 → "가입이 완료됐어요" 화면(시안). **실제 구현 시 현재 회원가입 완료 후 이동 동작(급여대장 업로드 화면으로 바로 이동, 11번)과 연결**
- 간편 가입: 카카오·구글·네이버 실제 로고. 기존 회원은 "급여 관리 이용 문의하기"(채널톡 `joberio.channel.io/home`)로 안내
- 브라우저 자동완성으로 채워져도 칸 배경이 파랗게 바뀌지 않게 처리
- 확인 필요: '어떻게 알고 오셨나요?'가 현재 가입 필수값인지, 선택지 목록(지금은 예시)

## 개발 시 참고

- **화면 속 이름, 금액, 이메일은 모두 예시 데이터.** 사업소득 표는 옆 목업과 높이를 맞추려고 예시 직원 3명(강도윤, 윤서아, 임하준)을 추가해 사업(5)로 표시
- 하나은행 관련 이미지: `assets/hr/hana-symbol.png`(로고), `hana-payroll-send.png`(급여이체 전송 버튼 아이콘), `hana-jober-btn.png`(하나은행 화면의 jober 버튼) — 개선안에 들어 있던 이미지를 파일로 꺼낸 것
- 간편 가입 로고: `assets/logo-google.svg`, `assets/logo-naver.svg`, 카카오 말풍선은 HTML 안 인라인 SVG
- 목업 버튼·칩은 글자가 위아래 가운데 오도록 여백을 미세 조정함 (`payroll.css` 하단)
- 사이트 공통 검정 버튼(`.btn`)의 글자 높이는 이번에 건드리지 않음
- 12번 이후(체험 제한, 개발 요구사항)는 `개발전달-10-13.html`에 원본 그대로 있음. 정책 미확정, 개발팀 검토 필요
