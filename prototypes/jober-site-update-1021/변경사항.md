## 1. 요금제 페이지 교체 — `/tour/pricing`

지금 실서버는 상단바·푸터만 새 디자인이고 본문은 예전 요금제다. 본문 전체를 새 시안으로 바꾼다.

**바뀌는 내용**
- 상단 탭: 전자계약 요금제 · 마케팅 요금제 · HR 요금제 (밑줄 탭, 고른 탭은 파란 글씨 + 파란 밑줄). 주소 `#contract` `#marketing` `#hr`로 탭을 바로 열 수 있다.
- 탭별 상단 문구
  - 전자계약: 월 정액 없이 시작하고, / 많이 충전할수록 더 큰 혜택을 받는 자버 전자계약
  - 마케팅: 알림톡 한 건당 50원, 월 정액 없이 / 많이 충전할수록 더 큰 혜택을 받는 자버 알림톡
  - HR: 필요한 기능만 골라 시작하는 / 자버 HR 요금제
- 건당 요금 카드: 흰 카드 + 파란 아이콘 + 미리보기 이미지(자르지 않고 연한 파랑 판 안에) + "크게 보기"
- 마케팅 탭 채널 연동 카드 설명 두 줄: "카카오 비즈니스 채널을 연동하고 우리 회사 이름으로 보내세요 / 마케팅용 알림톡 발송을 위해서는 채널 연동이 필수입니다"
- 충전 플랜
  - 금액 목록: 추가지급은 화살표 태그(0% 회색, 20% 미만 연한 파랑, 20% 이상 진한 파랑, 골라도 색 그대로)
  - 1만·5만·20만원 아래에 혜택 배너 "많이 충전할수록 포인트를 더 드립니다" + 선물 상자 일러스트
  - 오른쪽 계산 상자(파랑): "○○만원 충전 혜택" / 알림톡 기준·계약문서 기준 전환 / 발송 가능 건수 · 정가 · 실제 단가 / VAT·차감 안내. 금액을 누르면 계산이 바뀐다
- 섹션 제목 "이용 방법"(기존 "충전하고, 발송하고, 차감됩니다" 대체), 단계 카드 + 포인트 환불 안내
- 부가서비스: 카드 없이 이미지 → 제목 → 설명 → 요금 → 링크, 2열
- HR 탭: 월 결제 / 약정 할인 요금(12개월 이상) 전환, 요금제 카드 4개(베이직에 "가장 많이 사용하는 요금제" 배지가 카드 위 테두리 왼쪽에 걸침), 엔터프라이즈(검정), 상세 사항, 부가서비스
- 하단에 떠 있는 회원가입 버튼(파랑 그라데이션): 탭별 문구가 바뀌고 HR 탭에서는 숨김, 푸터가 보이면 사라짐
- 모바일: 본문 계산 상자 대신, 충전 플랜이 화면에 있는 동안 하단 버튼 위에 계산 요약 바(기준 전환 포함)가 붙는다

**파일**
- `files/pricing/index.html`
- `files/pricing.css`
- `files/assets/pricing/` (미리보기 이미지 11개 + `bonus-gift.webp`)

**확인 필요**
- 하단 회원가입 버튼·모바일 계산 바와 실서버 오른쪽 아래 "문의"(채널톡) 버튼이 겹치지 않게 위치 조정
- 회원가입 버튼 → `jober.io/sign-up`, HR "선택하기" → 임시로 `jober.io/sign-up`. 실제 결제·선택 주소로 교체

- "소통의 모든 순간에 자버가 있습니다" 아래 두 번째 줄을 **커넥티아 · 펠로우즈 · 자버 CRM** 3개 카드로 바꾼다
- 3개 카드 모두 위 카드처럼 그림 위 · 글 아래로 크게 (태블릿은 1열 가로형, 모바일은 기존처럼 작은 가로형)
- 새 CRM 카드 (라임 배경)
  - 그림: AI 질문·답변 창 ("우리 고객을 이해하는 AI" / "한빛제조, 다음에 무엇을 확인해야 해?" / "추가 도입 검토를 준비할 때입니다 · 10월 28일 내부 검토 예정" / 고객·거래·대화·문서)
  - 태그 "AI 고객관리", 제목 "자버 CRM", 설명 "고객·거래·대화의 맥락을 연결하고 / 우리 업무에 맞게 유연하게 구성해요", 버튼 "CRM 알아보기" → CRM 랜딩(새 탭)

## 4. 카카오 알림톡 — 고객 사례 교체

"자버의 고객들은 이렇게 사용하고 있어요" 카드 3개 중

- **가운데**: 세무특공대 → **수원본바른한방병원**
  - 위 큰 칸: 정사각 로고 `review-bonbarun-logo.webp`, 아래 작은 칸: 가로 로고 `review-bonbarun-name.webp`
  - 태그: #고객 안내 #편리한 발송
  - 문구: 병원을 방문하는 고객분들께 이벤트 안내나 진료 일정 안내를 하고 있어요. 클릭 한번이면 개별 카카오톡으로 대량 발송을 할 수 있어 많은 고객에게 안내하기 편리해요.
- **세 번째 인트리**: 문구만 수정
  - 태그: #손쉬운 신청 #신청자 급증
  - 문구: 다양한 지원사업의 신청을 자버를 통해 받고 있어요. 문서 작성이 쉬운 자버 덕분에 신청자가 매년 늘어나고 예산이 늘었어요.
- 사례 문구는 고정 줄바꿈 없이 어절 단위로 자동 줄바꿈 (`word-break:keep-all`)

**파일**: `files/services/alimtalk/index.html`, `files/assets/alimtalk/review-bonbarun-logo.webp`, `files/assets/alimtalk/review-bonbarun-name.webp`, `files/v3-sub.css`
