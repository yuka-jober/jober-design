서브 메뉴 손잡이 + 호버 팝오버

손잡이안을 기본으로, 접힘 상태 호버 팝오버를 더했어요. 상단바는 기존 그대로예요.

연락처 전체 검색
P497.9P충전

1접힘 — 손잡이

  • 선택된 메뉴 오른쪽, 레일 바깥에 검정 › 손잡이
  • 손잡이 또는 선택된 메뉴 아이콘 클릭 → 펼침
  • 접히는 순간 한 번만 살짝 흔들림
  • 손잡이는 작게 보이지만 주변까지 눌림
  • 팝오버가 떠 있는 동안엔 손잡이를 숨김

2펼침 — 닫기 버튼

  • 서브 메뉴 제목 오른쪽 회색 사이드바 접기 아이콘 버튼
  • 마우스를 올리면 검정으로
  • 상단바는 기존 그대로 — 검색창 위치 변화 없음

3접힘 — 호버 팝오버

  • 선택된 메뉴·손잡이에 250ms 머물면 서브 메뉴가 겹쳐 뜸
  • 팝오버로 옮겨가는 동안 유지, 벗어나면 닫힘
  • 항목 클릭 → 이동 / 제목 옆 사이드바 열기 버튼 → 펼침 고정
  • 홈·AI·빠른발송 등 서브 메뉴 없는 메뉴는 제외
